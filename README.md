# MyRobloxGame
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "MyRobloxGame.rbxlx"
```

Next, open `MyRobloxGame.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Visual Settings

Before pressing Play, expand `ReplicatedStorage > GameSettings` in Studio and change these BoolValue properties:

- `ShadersEnabled`: color correction, bloom, depth of field, and film grain.
- `NightEnabled`: dusk time, dark ambient lighting, and atmospheric fog. Turn it off for daytime lighting.

Both settings also update immediately while the game is running.

## Edit-mode R15 Pose Tuner

The tuner is a local Studio plugin and is excluded from `default.project.json`, normal builds, and the published game.

1. Close Roblox Studio and run `run-pose-tuner.bat`.
2. Restart Studio and click **Plugins > Pose Tuner**. Do not enter Play mode.
3. The plugin displays the full pose-tuner overlay directly on Studio's 3D viewport, then creates the project Dummy (or a gray fallback R15) in a temporary Workspace arena. Closing the overlay removes the arena and restores the Studio camera.
4. Select limbs in the hierarchy or 3D viewport. Use Move, Rotate, or IK. Exact `Motor6D.Transform` CFrames are captured by **Key Pose**.
5. `W/S` zoom and `A/D` pan. While holding middle mouse, drag to orbit and use WASD to fly. The wheel also zooms.
6. Segment easing supports every Roblox Tween style with In, Out, and InOut directions. Playback begins at the earliest key; earlier empty time holds that first pose.
7. Use **Save New** or **Update** in the local Animation Catalog. Animations, the recovery draft, selected dummy, recent list, and hidden list persist through Studio restarts without HTTP.
8. V3 exports preserve exact 12-component CFrames. Existing V1 and V2 animation text remains importable.

Custom dummies can be pasted permanently into `ReplicatedStorage > PoseTunerDummies`, or selected in Workspace and added with **Import Selection**. The model must be a complete Motor6D R15 rig. The generated `DefaultGrayR15` cannot be hidden.
